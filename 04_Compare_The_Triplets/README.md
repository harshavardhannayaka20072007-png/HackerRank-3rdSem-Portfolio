# Compare the Triplets

## Official HackerRank problem statement
Access the official statement here:
- https://www.hackerrank.com/challenges/compare-the-triplets/problem

## Problem summary
Alice and Bob each receive three integer scores. For each of the three categories, the person with the larger score gains a point. The task is to print the total points for Alice and Bob.

This folder contains the completed C solution in `solution.c`.
