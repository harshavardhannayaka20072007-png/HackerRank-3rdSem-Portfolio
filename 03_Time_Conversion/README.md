# Time Conversion

## Official HackerRank problem statement
Access the official statement here:
- https://www.hackerrank.com/challenges/time-conversion/problem

## Problem summary
Convert a time from 12-hour format (for example, 07:05:45PM) into 24-hour format. The output must always be formatted as HH:MM:SS.

This folder contains the completed C solution in `solution.c`.
