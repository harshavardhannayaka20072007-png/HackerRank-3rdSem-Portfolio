# HackerRank Practice Solutions in C

This repository contains C implementations of selected HackerRank practice problems.

## Challenges

1. [01_Diagonal_Difference](01_Diagonal_Difference/README.md)  
   Calculates the absolute difference between the sums of the two diagonals in a matrix.

2. [02_Dynamic_Array](02_Dynamic_Array/README.md)  
   Implements dynamic sequences using XOR-indexed access and dynamic storage.

3. [03_Time_Conversion](03_Time_Conversion/README.md)  
   Converts time from 12-hour format to 24-hour format.

4. [04_Compare_The_Triplets](04_Compare_The_Triplets/README.md)  
   Compares two triplets and returns the resulting score.

5. [05_Sparse_Arrays](05_Sparse_Arrays/README.md)  
   Counts how many times each query string appears in the input strings.

## Notes

- Each problem folder includes a C source file named `solution.c`.
- The README files describe the same logic implemented in the corresponding C code.
- You can compile any solution with a command like:

```bash
gcc 01_Diagonal_Difference/solution.c -o diagonal
./diagonal
```
